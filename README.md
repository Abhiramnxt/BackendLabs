## 📖 About This Repository

This repository contains my practical work and lab assignments for the **Backend Development Fundamentals** course.

The labs progressively cover backend development concepts including:
- Node.js fundamentals
- Express.js server development
- REST API design
- SQLite database integration
- CRUD operations
- Query parameters and filtering
- Sorting and pagination
- Input validation
- Error handling

- Git and GitHub

## 📌 Development Practices

The projects follow standard backend development practices:
- Use parameterized SQL queries.
- Validate incoming request data.
- Return appropriate HTTP status codes.
- Handle invalid resource requests.
- Keep database operations asynchronous.
- Avoid committing sensitive `.env` files.
- Do not commit `node_modules`.
- Maintain separate folders for each lab.
- Test APIs locally before deployment.
- Verify deployed APIs after deployment.

## ☁️ Deployment

The backend applications are deployed using **Render**.

Each lab is configured as an independent web service using its respective lab directory as the deployment root.
